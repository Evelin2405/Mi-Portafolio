## 🏷️ Lanzamiento de Versión (v1.0)

### 🛠️ Conceptos Clave de Git Aprendidos
* **Git Stash:** Nos permite ocultar temporalmente cambios en un "escondite" para limpiar nuestro espacio de trabajo sin perder código.
* **Git Tag:** Sirve para marcar hitos o lanzamientos de versiones importantes en el historial del repositorio.
